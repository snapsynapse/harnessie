Six new deterministic evals cover approval precedence, resume drift and adversarial stand-down (76 total). Two independent fresh-context reviews challenged the first repairs for bypasses and false positives; the confirmed gaps were repaired in a second round (resume false positives on crash recovery and fix-then-resume, whole-call transport deadline, unknown-usage remedy and per-tier `unmetered`, evidence truncation sentinel, launched-check exit contract, macOS `os.waitid` fallback, decision-record control characters and autolinks). A third independent review found and helped close two further gaps in check exit precedence and resume binding. A separate output-cap review tried 378 synthetic cut cases across seven credential shapes with zero leaked prefixes. PR #46's proxy CONNECT accounting review finding was fixed with a loopback regression. The final local locked release gate passed 2,319 tests, 4 skipped, 28 expected failures and 76 evals; PR and merged-main CI passed.

The last audit finding, `DEP-20261118-001`, has a source repair: the build backend floor is `setuptools>=84.1.0`, and the dev/release locks resolve 84.2.1 with pinned uv 0.13.4. The runtime lock and every other pin are unchanged. Lock validation, focused tests, pip-audit for all three profiles, the local release gate and exact-commit CI passed.

Contract change for downstreams: a check that never launched (missing or non-executable program, malformed command, sandbox refusal) is now exit 2 instead of 1. Launched checks that fail, time out or escape cleanup remain exit 1. Verify Action, Ringer and Harbor consumers receive this behavior only after adopting the published 1.5.1 core.

Residual risks recorded by the reviews, not repaired: a `setsid` descendant that closes its pipes is neither detected nor killed; raw `proofs/check-*.txt` keep unredacted check output as operator artifacts; a bad shebang or `/usr/bin/env missing-tool` check is classified FAILED; resume binding does not cover `config/models.yaml`, memory contents, ownership, approval or boundary configuration; a run stopped for unknown usage cannot be resumed (start a new run); a crash-time edit to an earlier phase's output refuses resume; an operator edit to a path a rerunning halted phase last touched can refuse one resume later; the transport watchdog does not bound an HTTPS proxy CONNECT handshake; a read-only parent directory surfaces as a raw PermissionError from `write_file`; Linux bubblewrap, firejail and docker backends were not exercised by these repairs. The `read_file` and `run_shell` cap-crossing prefix is now withheld, including ordinary long trailing tokens; verify proof output has a separate path.
